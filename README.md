# AI Companion v0.9

Почти полноценная система компаньона с возможностью подключать LLM и TTS.

## Включено

- Стандартный бот из Source + скрипты для взаимодействия
- Настройки локального LLM (LM Studio) и TTS (ComfyUI)
- Частичная поддержка в одиночной игре (без бота)
- Облачные решения LLM и TTS (экспериментально)
- Поддержка Glide (частично) и HL2 транспорта ботом
- Разные языки для игроков из других стран (возможны ошибки перевода, обязательно сообщите)
- Меню аддона (настройки LLM и TTS, бота, команды, внешний вид префикса)
- Кастомизация префикса AI в чате
- «Приватный» чат с AI в мультиплеере (`!ai` в чат)

## Как заспавнить бота

Перейдите в **Q меню → Утилиты → AI Companion** или через консольную команду ai_companion_menu

(если совсем всё плохо – `ai_companion_create`)

> **В одиночной игре бот не доступен из-за ограничений Source**, но остальной функционал аддона работает (включая меню аддона).

## Инструкция

### Облачные LLM и TTS

1. Переключите режим во вкладке **Основное**: `LLM` и `TTS` – с **Локальный/Отключено** на **Облачный**.
2. Введите данные:
   - **LLM**: модель, API-ключ, кастомный эндпоинт (опционально)
   - **TTS**: API-ключ, голос (код), язык (на английском), кастомный эндпоинт (опционально)

> ⚠️ **Внимание!** Не используйте API-ключи на серверах, которым вы НЕ доверяете!

### Локальные LLM и TTS

#### Настройка LLM (LM Studio)

1. Включите режим **Разработчика**
2. Перейдите во вкладку **Сервер**
3. Откройте настройки сервера (шестерёнка)
4. Включите:
   - **Обслуживание по локальной сети** (Garry's Mod не слушает localhost)
   - **Включить CORS** (обязательно)
5. Загрузите любую модель (отключите режим **Думающий**)
6. Запустите сервер
7. Скопируйте ваш IP → поле **LLM IP (Локальный)**
8. Скопируйте порт (по умолчанию `1234`) → поле **Порт LLM (Локальный)**
9. Скопируйте название модели (`API Model Identifier`) → поле **Модель LLM (Локальная)**
10. Переключите режим LLM на **Локальный**
11. Нажмите **Проверить подключение к серверам** в меню
12. Проверьте консоль на ответ
13. Напишите любое сообщение в чат
14. Готово.

#### Настройка TTS (только ComfyUI, по умолчанию отключён)

1. Отредактируйте `.bat` файл ComfyUI, добавьте: --listen 0.0.0.0 --enable-cors-header
2. Перейдите в **ComfyUI → Файл → Экспортировать (API)** → дайте название на английском языке **БЕЗ пробелов**.
3. Переместите ваш `.json` файл в `Garry's Mod/garrysmod/data`

**Настройте меню:**

1. Перейдите во вкладку **Workflow → Загрузить Workflow** → введите название файла (например: `myjsonworkflow.json`)
2. Нажмите на **«Включить/Отключить Workflow»** (по умолчанию отключена)
3. Нажмите на **«Показать статус»**
4. Перейдите во вкладку **Основное**
5. **TTS IP (Локально)** – ваш IP
6. **Порт TTS** – `8188` (по умолчанию)
7. Включите **TTS → Локально**
8. Включите **TTS Персональный**
9. Нажмите **Проверить подключение к серверам**
10. Проверьте консоль
11. Напишите сообщение в чат
12. Дождитесь генерации LLM
13. Дождитесь генерации TTS
14. Слушайте.

> Если голос не появился, **проверьте файл** в `ComfyUI/output/audio/` – должно быть `ComfyUI_цифры.mp3` или проверьте JSON-файл.
